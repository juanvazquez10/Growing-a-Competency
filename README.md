# Growing-a-Competency
Practice repository for learning Git and GitHub as part of my competency assignment.

## What I learned
- How to create and initialize a repository on GitHub with my own key
- How to clone a repository using SSH
- How to stage, commit, and push changes using Git commands
- How to update and track files
- How to sync local and remote repositories to maintain version control
- How to make good commits and how to make a README file

## Files included 
- **README.md** - Overview of the project and what I learned (The one you're reading right now lol)
- **progress.txt.** - Log describing what I learned, but mainly to show that I can push and commit to here
